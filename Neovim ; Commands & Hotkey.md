# Commands

- `sp` / `sp <file>` — Split horizontally / Split horizontally and open a file;
- `vsp` / `vsp <file>` — Split vertically / Split vertically and open a file;

# Tricks

- Find and replace an instance of a string:
	- `:%s/<from>/<to>/g`
- Find and replace a string globally:
	- `:%s/<from>/<to>/g`

# Hotkeys

- `Ctrl + W + `
	- `S` — Horizontal split;
	- `V` — Vertical split;
	- `W` — Switch forcus to the next tab;
	- `H`/`J`/`K`/`L` — Switch tab forcus in a specific direction;
