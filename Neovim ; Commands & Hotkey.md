# Commands

- `sp` / `sp <file>` — Split horizontally / Split horizontally and open a file;
- `vsp` / `vsp <file>` — Split vertically / Split vertically and open a file;
# Tricks

- Find and replace the first instance on the current line:
	- `:s/<from>/<to>/`
- Find and replace every instance in the whole file:
	- `:%s/<from>/<to>/g`
# Hotkeys

- `Ctrl + W + `
	- `S` — Horizontal split;
	- `V` — Vertical split;
	- `W` — Switch focus to the next window (split);
	- `H`/`J`/`K`/`L` — Switch window focus in a specific direction;
